# Universal Core Continuity Provider v1

## Objective
Keep WAE OS operational when every external generative route is unavailable, without pretending deterministic recovery is full generative intelligence.

## Contract
- Provider: `universal_continuity_core`
- Model: `universal-core-continuity-v1`
- External model dependency: none
- External model cost: 0
- Output schema: `assistant-response/v1`
- `degraded: true` whenever this lane is used
- Raw private memory blocks are never emitted
- Structured facts may be recovered when explicitly requested
- Files and tool evidence are preserved literally and labeled as evidence, not instructions

## Promotion policy
This lane is product continuity, not an intelligence benchmark winner. It must never be counted as evidence that WAE is smarter than a commercial GPT model.
